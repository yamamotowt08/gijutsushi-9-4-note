# 技術士 9-4 答案ノート

技術士第二次試験〔建設部門〕選択科目 9-4「河川、砂防及び海岸・海洋」の学習用ページです。

- 令和元年度〜令和8年度の選択科目Ⅱ・Ⅲ（全64問）の模範解答
- 令和9年度の予想問題9問と模範解答
- 出題傾向の一覧と分析、答案の書き方
- **練習**：答案を書いて行数（24字×25行）をその場で確認、時間計測、本番セット（Ⅱ-1・Ⅱ-2・Ⅲを3時間30分）、キーワードと答案の形の自己採点、模範解答との比較
- **暗記カード**：要点まとめの見出しごとのカード（間隔をあけて復習）
- **学習記録**：進み具合・苦手な問題・最近の練習・学習した日、記録の書き出しと読み込み

## 注意

- 問題文の出典：公益社団法人日本技術士会「技術士第二次試験問題〔建設部門〕」令和元年度〜令和8年度。
- 模範解答と予想問題は学習用に作成したもので、同会の公式な解答ではありません。数値・制度名は最新の基準類で確認してください。
- 予想問題は過去問の傾向と政策動向からの推定で、的中を保証するものではありません。
